# 陣地取り大戦 ～1日1マスと核の時代～

ブラウザで遊べるターン制の陣地取りゲーム。1日に1マスだけ、となりのマスを**取る**か、
自分のマスを**守る**。CPUの国も毎日1マスずつ動く。金を貯めて都市・ミサイル基地・迎撃基地を建て、
核ミサイルで敵の陣地を吹き飛ばそう。

## 遊び方

`index.html` をブラウザで開くだけ（ビルド不要・サーバー不要）。GitHub Pages でもそのまま公開できます。

- マスをタップして選び、「取る！」/「守る」で決定（同じマスをもう一度タップしても決定）
- **取る**：自分の陣地のとなりのマス（無人・敵）を自分のものにする
- **守る**：自分のマスに🛡盾を置く。盾のあるマスを攻められると、盾がこわれるだけで取られない
- 行動すると日が進み、CPUの国もそれぞれ動く。「次の日へ」で休むこともできる
- 💰金は毎日「マス数＋α」もらえる。建物と核は金だけで使え、1日の行動は減らない
- 🏙 **都市**：毎日の金が増える
- 🚀 **ミサイル基地**：核の発射に必要（撃ったら2日間再装填）
- 🛡 **迎撃基地**：まわり5マス以内に飛んでくる核を撃ち落とす（MIRVは迎撃不可）
- ☢ **原子爆弾** / 💥 **水素爆弾** / 🎆 **MIRV**（相手の陣地に6発の弾頭）。被爆したマスは無人に戻り、数日間だれも取れない
- 100日のシーズン終了時に1位、または陸地の60%を取るか敵を全滅させれば勝利
- キーボード：`1`〜`3` 建設、`4`〜`6` 核、`Enter` 決定、`N` 次の日へ、`Esc` 解除

## ファイル構成

- `index.html` — 画面レイアウト
- `style.css` — UI スタイル
- `game.js` — マップ生成・ゲームロジック・CPU・描画
