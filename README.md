# 陣地取り大戦 ～核の時代～

ブラウザで遊べる陣地取りゲーム。となりのマスをタップして兵を送り込み、領土を広げ、
都市・ミサイル基地・迎撃基地を建て、核ミサイルで敵国を吹き飛ばそう。

## 遊び方

`index.html` をブラウザで開くだけ（ビルド不要・サーバー不要）。GitHub Pages でもそのまま公開できます。

- **タップ / クリック**：となりの無人地帯・敵国へ攻撃（スライダーで送る兵力の割合を調整）
- **ドラッグ**：マップ移動　**ピンチ / ホイール**：ズーム
- 🏙 **都市**：最大兵力 +5000、金収入アップ
- 🚀 **ミサイル基地**：核の発射に必要（発射後しばらく再装填）
- 🛡 **迎撃基地 (SAM)**：範囲内に飛んでくる核を撃ち落とす
- ☢ **原子爆弾** / 💥 **水素爆弾** / 🎆 **MIRV**（相手国全体に14発の弾頭、迎撃不可）
- 被爆したマスは放射能で汚染され、しばらく占領しにくくなる
- キーボード：`1`〜`3` 建設、`4`〜`6` 核、`Esc` / 右クリックで解除、`P` で一時停止

全陸地の 80% を支配するか、すべての敵国を滅ぼせば勝利。

## ファイル構成

- `index.html` — 画面レイアウト
- `style.css` — UI スタイル
- `game.js` — マップ生成・ゲームロジック・AI・描画
