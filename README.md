# 47都道府県対抗 陣取り合戦

日本地図を細かいマスに区切り、47都道府県で奪い合うスマホ縦画面向けブラウザゲーム（試作版）。2つの遊び方があります。

| | 1人用（`index.html`） | オンライン版（`online.html` ＋ `server/`） |
|---|---|---|
| マス | 約541万マス（1マス≒270m） | **約4870万マス（1マス≒90m）**。1県にアクティブ500人でも1人数百マスの土地 |
| 動く場所 | 端末の中（AIと対戦） | サーバーが地図とルールを持ち、各端末には画面の周りだけを送る |
| 人数 | あなた＋AI | 登録1万人・同時接続1000人を想定（空いている席はAIが担当） |

`index.html` は1ファイルだけで動きます（地図データ・WebGL描画・ゲームすべて埋め込み、外部ライブラリなし）。

## 遊び方（建築ストラテジー版）
`index.html` をブラウザで開く → 自分の県を選んで「この県で出陣」。

- あなたは県の参加者の1人（全国で約1000人。今はあなた以外をAIが担当）。部隊は操作せず、**建物を建てて国を育て、兵を送る**。
- 下の建築メニューでカードを選び、**自県の領土（明るく表示）をタップ**して建てる。資源は食料🌾・木材🪵・金💰。

| 建物 | 費用 | 働き |
|---|---|---|
| 🌾 農場 | 木60 | 食料 +1.2/秒（森を切り開くと半分、山は不可） |
| 🪓 製材所 | 木40・金20 | 周りの森の量に応じて木材（最大 +2/秒）。森の近くのみ |
| 🏪 市場 | 木120 | 金 +1/秒 |
| ⚔️ 兵舎 | 木150・金50 | 食料30で8秒ごとに兵士を訓練。兵士は自動で県の攻め先へ進軍 |
| 🗼 見張り塔 | 木80・金60 | 近くの敵兵を撃つ |
| 🏘️ 町 | 木250・金150 | 新しい拠点。国境を広げる・金 +0.8/秒 |
| 🏰 砦 | 木150・金300 | 新しい拠点。国境を広げ、敵兵を撃つ |

- 敵の拠点（県庁・町・砦）は兵士が居座ると占領でき、その周りの**領土と建物がまとめて自県のもの**になる。守りのない建物は敵兵に壊される。
- 「⚔ 攻撃目標」で敵の拠点をタップすると、あなたの兵舎の兵士がそこを攻める。
- 全国の陸地の50%で勝利、自県の拠点が0で敗北。
- 操作：ドラッグで移動、ピンチ／ホイールで拡大縮小（拡大すると森の木や建物が見える）。PCは矢印キー/WASD、`+`/`-`、`1`〜`7` 建物を選ぶ、`R` 攻撃目標、`T` 真上ビュー、`H` 自県へ、`Esc` やめる。

## ファイル構成
| パス | 内容 |
|---|---|
| `index.html` | 完成品（ビルド生成物） |
| `src/core.js` | CONFIG・建物の定義・マップ展開（標高PNGも）・カメラ・WebGL描画（地形の陰影・浅瀬・国境線、インスタンス描画の建物・兵士・木） |
| `src/sprites.js` | 兵士の絵（スプライト）。起動時に Canvas 2D で、関節の姿勢を5方向に投影して輪郭線と陰影つきで描き、1枚の絵にまとめる（県の色は別のマスクに描いて表示時に乗せる） |
| `src/rts_sim.js` | ルールとAI（資源・建物・兵舎の訓練・兵士・戦闘・占領・国境・経路探索、県AIの建築と作戦）。描画から独立し、固定刻みで進むので、将来サーバーで同じものを動かせる |
| `src/net.js` | オンライン版の通信（`NetGame`：Sim と同じ形で app.js から使える）と、細かい座標の地図（`scaledMap`） |
| `src/app.js` | 画面・入力・ステートマシン（LOADING / TITLE / PLAYING / GAMEOVER） |
| `online.html` | オンライン版の画面（ビルド生成物。サーバーが配る） |
| `server/server.js` | オンライン版のサーバー（Node.js ＋ ws）。ルールは `src/core.js`・`src/rts_sim.js` をそのまま読み込む |
| `deploy/` | さくらVPS などに置くときの systemd・nginx の設定例 |
| `tests/online_tests.js` | オンライン版のテスト（通信の手順・建設・つなぎ直し・同時接続の負荷・ブラウザ） |
| `src/style.css`, `src/template.html` | 画面レイアウト |
| `tools/preprocess.py` | 地図データの前処理 → `data/mapdata.json`（拠点の配置もここで決める）、確認画像 `data/preview/*.png` |
| `tools/prefdata.py` | 県名・人口・県庁所在地、連絡マス（トンネル・橋・航路）、市街地の種になる都市 |
| `tools/build.py` | `src/` と `data/mapdata.json` を `index.html` に組み立て |
| `tests/run_tests.js` | Playwright 自動テスト |

## ビルド
```sh
pip install numpy pillow scipy
python3 tools/preprocess.py   # data/japan.topojson → data/mapdata.json（標高タイルは data/dem_cache/ にキャッシュ）
python3 tools/build.py        # → index.html
node tests/run_tests.js       # Playwright テスト（MINUTES=20 などで長時間テストのゲーム内分数を変更）
```

## オンライン版（さくらVPS などのサーバー）
### しくみ
- サーバーは元の地図（541万マス）の1マスを3×3に分けた **21600×22590マス（陸地4870万マス）** の地図でシーズンを進める。
  県・地形・海岸は元の地図と同じで、領土・建物・兵士の位置が3倍細かい（兵士と建物の大きさはマス単位でそのまま）。
  距離にかかわる調整値（国境の広さ・兵士の速さ・経路のブロックなど）は3倍にして、ペースは1人用と同じにしている。
- 端末へ送るもの：
  - 日本全体の持ち主（元の地図の1マスごと。「元の県のまま」は0として送るので最初は数バイト）と、その変化
  - 拡大しているときだけ、画面の周りの細かいマスの持ち主（64×64マスの区画、最大400区画）
  - 画面に映っている範囲の兵士（0.5秒ごと。端末で補間して動かす）と建物（変わったものだけ）、拠点の変化、資源・順位
- 参加：県を選んで「出陣」。参加の印（トークン）を端末に保存し、同じ端末なら同じ県・同じ財布で続きから遊べる。
  抜けても建物と資源は残る。各県の参加者数は「人口から決まる席数」と「人間の参加者数」の多い方で、空いている席をAIが担当。
- シーズンが終わると10分後に次のシーズンが始まる（つないでいる人は自動で読み込み直す）。

### 測った数字（テスト環境・`node tests/online_tests.js`、`BOTS=1000` で1000人）
| | 値 |
|---|---|
| 起動 | 約12秒（地図の展開1秒・国境の計算11秒） |
| メモリ | 約1.0GB（1000人接続で約1.3GB） |
| ルールの計算 | 0.25秒ぶんで約1〜2ミリ秒 |
| 送信の処理 | 0.5秒ごとに、300人で約37ミリ秒・1000人で約124ミリ秒（1コアの約25%） |
| 通信量 | 1人あたり約3KB/秒（圧縮後）。1000人で約3MB/秒（約25Mbps） |

→ さくらVPSなら **メモリ4GBのプラン（4コア）** で同時接続1000人の目安に収まる。2GBプランでも動くが余裕は少ない。

### 置き方（Ubuntu の例）
```sh
sudo apt install -y nodejs npm nginx
sudo useradd -r -m jinchi && sudo git clone <このリポジトリ> /opt/jinchi-tori-game && sudo chown -R jinchi /opt/jinchi-tori-game
cd /opt/jinchi-tori-game && sudo -u jinchi npm install --omit=dev      # ws だけ入る
sudo cp deploy/jinchi47.service /etc/systemd/system/ && sudo systemctl daemon-reload && sudo systemctl enable --now jinchi47
sudo cp deploy/nginx.conf /etc/nginx/sites-available/jinchi47     # server_name を書きかえる
sudo ln -s /etc/nginx/sites-available/jinchi47 /etc/nginx/sites-enabled/ && sudo nginx -s reload
sudo certbot --nginx -d あなたのドメイン                             # HTTPS（wss）
```
手元で試すなら `npm install --omit=dev && node server/server.js` → `http://localhost:8080/`。
環境変数：`PORT`（8080）・`GRID_SCALE`（3）・`SEED`・`SPEED`（確認用の早送り）・`RESTART_MS`（終了後に次を始めるまで）。

### まだないもの（次の段階）
- シーズンの保存：サーバーを再起動すると、そのシーズンは最初からになる（定期的にファイルへ保存する仕組みが必要）
- ログイン（今は端末に保存した印だけ。機種変更すると引き継げない）・名前の表示・チャット
- 不正対策（送信回数の制限など）

## 地図データの作り方
- 都道府県境・海岸線：[dataofjapan/land](https://github.com/dataofjapan/land) の `japan.topojson`（出典：地球地図日本（国土地理院））。
- グリッド：経度0.003°×緯度0.0024°（1マス≒270m×265m）、7200×7530マス（東経128.25°〜、北緯45.65°〜）、陸地 5,410,698マス。
  陸地を含む 64×64 マスの区画だけを持つ。オンライン版はこれをサーバーで3×3に分ける（`MapData.upscale`）。
- インセット：本土から離れすぎる島はずらして配置し、枠と説明を表示。
  - 南西諸島（沖縄県＋奄美・トカラ）… 九州の南西（地図の左下）に階段状の枠で表示。沖縄本島〜奄美は（経度+5.52°, 緯度+1.8°）、
    先島諸島は本島の西へ寄せて（+5.52°, +3.8°）、大東諸島は本島の東へ寄せて（+4.52°, +3.4°）ずらす
  - 小笠原・硫黄島（+3.5°, +8°）、南鳥島も小笠原の近くへ
- 地形：AWS Terrain Tiles（z8）の標高・傾斜と主要都市の位置から、平地／森／山／市街地を判定。雪は緯度と日本海側の雪線から判定。
- 圧縮：県IDと地形をそれぞれ RLE（値＋可変長整数）＋ base64。
- 県境・海岸線：topojson のアークを共有数で県境／海岸線に分け、ダグラス・ポイカー法（許容0.45マス）で簡略化したベクター線。
- 連絡マス：青函トンネル、関門、明石海峡大橋、大鳴門橋、瀬戸大橋、しまなみ海道、アクアライン、沖縄航路、宮古・八重山・大東航路など21ルート。
  ほかの小島は最寄りの陸地へ自動でつなぎ、全国の陸地がひとつながりになるようにしている（自動の連絡線はインセットの枠をまたがない）。
- 配色：CIELABの色差（ΔE76）で、隣接県（連絡マスでつながる県を含む）の最小色差を最大化するよう焼きなまし法で割り当て。
  現在の結果は **隣接県の最小ΔE = 72.8**、全47色の最小ΔE = 12.1。

## シーズン（7日間）とバランス
- 24時間ずっと進むゲームで、1シーズンは**7日間**。7日目の終わりに**支配人口**（支配している土地に住む人口）が一番多い県が優勝。それより前に全国の人口の50%を支配すれば即優勝。
- 順位を土地の広さではなく支配人口にしているのは、参加者数が人口に比例しているため（北海道のように広い県が有利になりすぎない）。
- ペースの目安：兵士は県をまたぐのに数分、兵舎は10分に1人、建物は30〜60分に1つ、町の占領は（攻撃側−守備側）の人数差15人で約20分。
- `node tools/season_sim.js 7 2 1` で、画面なしで7日間を早送りして戦況を確認できる（約50分）。`SCALE=3` を付けるとオンライン版の細かい地図で回す。
  - 例（1人用の地図・seed 1）：7日目の終わりに 東京19.2%・大阪18.4%・福岡15.9%（支配人口）、15県が脱落、占領3496回。ブラウザでは `index.html?speed=600` で1秒＝10分の早送り。

## 主な調整値（`src/core.js` の `CONFIG` と `BUILDINGS`）
資源（`START_RES`・`BASE_INCOME`）、建物の費用と働き（`BUILDINGS`）、兵士（`UNIT_*`）、占領（`CAPTURE_*`）、国境（`NODE_RADIUS`）、
AIの建築頻度（`AI_BUILD_INTERVAL`）、領土の塗りの濃さ（`FILL`）、木の本数（`TREE_MAX`）など。

## 性能の目安
1人用：陸地約541万マス。シミュレーション1刻みあたり平均3〜4ミリ秒（テスト環境）。7日間のシーズンを画面なしで回すと約50分（`tools/season_sim.js`）。
建物・兵士・木・影はインスタンス描画で、メッシュの種類ごとに1回の描画命令。拡大したとき（1マスが画面で約2.6px以上）だけ窓・煙突・畑の畝・兵士の手足などの細部を描く。
持ち主と地形は1枚のテクスチャ（1マス2バイト）。オンライン版はこれに細かい持ち主の層（2048×2048、1マス1バイト）を重ねる。
