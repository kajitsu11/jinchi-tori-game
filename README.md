# 47都道府県対抗 陣取り合戦

日本地図を約61万マスに区切り、47都道府県で奪い合うスマホ縦画面向けブラウザゲーム（試作版）。
`index.html` 1ファイルだけで動きます（地図データ・WebGL描画・ゲームすべて埋め込み、外部ライブラリなし）。

## 遊び方（建築ストラテジー版）
`index.html` をブラウザで開く → 自分の県を選んで「この県で出陣」。

- あなたは県の参加者の1人（全国で約1000人。今はあなた以外をAIが担当）。部隊は操作せず、**建物を建てて国を育て、兵を送る**。
- 下の建築メニューでカードを選び、**自県の領土（明るく表示）をタップ**して建てる。資源は食料🌾・木材🪵・金💰。

| 建物 | 費用 | 働き |
|---|---|---|
| 🌾 農場 | 木60 | 食料 +1.2/秒（森を切り開くと半分、山は不可） |
| 🪓 製材所 | 木40・金20 | 周りの森の量に応じて木材（最大 +2/秒）。森の近くのみ |
| 🏪 市場 | 木120 | 金 +1/秒 |
| ⚔️ 兵舎 | 木150・金50 | 食料30で8秒ごとに兵士を訓練。兵士は自動で県の攻め先へ進軍 |
| 🗼 見張り塔 | 木80・金60 | 近くの敵兵を撃つ |
| 🏘️ 町 | 木250・金150 | 新しい拠点。国境を広げる・金 +0.8/秒 |
| 🏰 砦 | 木150・金300 | 新しい拠点。国境を広げ、敵兵を撃つ |

- 敵の拠点（県庁・町・砦）は兵士が居座ると占領でき、その周りの**領土と建物がまとめて自県のもの**になる。守りのない建物は敵兵に壊される。
- 「⚔ 攻撃目標」で敵の拠点をタップすると、あなたの兵舎の兵士がそこを攻める。
- 全国の陸地の50%で勝利、自県の拠点が0で敗北。
- 操作：ドラッグで移動、ピンチ／ホイールで拡大縮小（拡大すると森の木や建物が見える）。PCは矢印キー/WASD、`+`/`-`、`1`〜`7` 建物を選ぶ、`R` 攻撃目標、`T` 真上ビュー、`H` 自県へ、`Esc` やめる。

## ファイル構成
| パス | 内容 |
|---|---|
| `index.html` | 完成品（ビルド生成物） |
| `src/core.js` | CONFIG・建物の定義・マップ展開（標高PNGも）・カメラ・WebGL描画（地形の陰影・浅瀬・国境線、インスタンス描画の建物・兵士・木） |
| `src/rts_sim.js` | ルールとAI（資源・建物・兵舎の訓練・兵士・戦闘・占領・国境・経路探索、県AIの建築と作戦）。描画から独立し、固定刻みで進むので、将来サーバーで同じものを動かせる |
| `src/app.js` | 画面・入力・ステートマシン（LOADING / TITLE / PLAYING / GAMEOVER） |
| `src/style.css`, `src/template.html` | 画面レイアウト |
| `tools/preprocess.py` | 地図データの前処理 → `data/mapdata.json`（拠点の配置もここで決める）、確認画像 `data/preview/*.png` |
| `tools/prefdata.py` | 県名・人口・県庁所在地、連絡マス（トンネル・橋・航路）、市街地の種になる都市 |
| `tools/build.py` | `src/` と `data/mapdata.json` を `index.html` に組み立て |
| `tests/run_tests.js` | Playwright 自動テスト |

部隊を1つ動かすRTS版はコミット `7eaed2d`、1日1回行動の旧版（核・MIRV・毒ガス・迎撃基地入り）はコミット `1d2c605` に残っています。

## ビルド
```sh
pip install numpy pillow scipy
python3 tools/preprocess.py   # data/japan.topojson → data/mapdata.json（標高タイルは data/dem_cache/ にキャッシュ）
python3 tools/build.py        # → index.html
node tests/run_tests.js       # Playwright テスト（MINUTES=20 などで長時間テストのゲーム内分数を変更）
```

## 地図データの作り方
- 都道府県境・海岸線：[dataofjapan/land](https://github.com/dataofjapan/land) の `japan.topojson`（出典：地球地図日本（国土地理院））。
- グリッド：経度0.006°×緯度0.0048°（1マス≒540m×530m）、3600×3765マス（東経128.25°〜、北緯45.65°〜）、陸地 1,364,598マス。
- インセット：本土から離れすぎる島はずらして配置し、枠と説明を表示。
  - 南西諸島（沖縄県＋奄美・トカラ）… 九州の南西（地図の左下）に階段状の枠で表示。沖縄本島〜奄美は（経度+5.52°, 緯度+1.8°）、
    先島諸島は本島の西へ寄せて（+5.52°, +3.8°）、大東諸島は本島の東へ寄せて（+4.52°, +3.4°）ずらす
  - 小笠原・硫黄島（+3.5°, +8°）、南鳥島も小笠原の近くへ
- 地形：AWS Terrain Tiles（z8）の標高・傾斜と主要都市の位置から、平地／森／山／市街地を判定。雪は緯度と日本海側の雪線から判定。
- 圧縮：県IDと地形をそれぞれ RLE（値＋可変長整数）＋ base64。
- 県境・海岸線：topojson のアークを共有数で県境／海岸線に分け、ダグラス・ポイカー法（許容0.45マス）で簡略化したベクター線。
- 連絡マス：青函トンネル、関門、明石海峡大橋、大鳴門橋、瀬戸大橋、しまなみ海道、アクアライン、沖縄航路、宮古・八重山・大東航路など21ルート。
  ほかの小島は最寄りの陸地へ自動でつなぎ、全国の陸地がひとつながりになるようにしている（自動の連絡線はインセットの枠をまたがない）。
- 配色：CIELABの色差（ΔE76）で、隣接県（連絡マスでつながる県を含む）の最小色差を最大化するよう焼きなまし法で割り当て。
  現在の結果は **隣接県の最小ΔE = 72.8**、全47色の最小ΔE = 12.1。

## 主な調整値（`src/core.js` の `CONFIG` と `BUILDINGS`）
資源（`START_RES`・`BASE_INCOME`）、建物の費用と働き（`BUILDINGS`）、兵士（`UNIT_*`）、占領（`CAPTURE_*`）、国境（`NODE_RADIUS`）、
AIの建築頻度（`AI_BUILD_INTERVAL`）、領土の塗りの濃さ（`FILL`）、木の本数（`TREE_MAX`）など。

## 性能の目安
陸地約136万マス。10分ほど進めると兵士約2700・建物約5000・拠点約750。シミュレーション1刻み（0.1秒分）あたり平均3〜4ミリ秒（テスト環境）。
建物・兵士・木・影はインスタンス描画で、メッシュの種類ごとに1回の描画命令。拡大したとき（1マスが画面で約2.6px以上）だけ窓・煙突・畑の畝・兵士の手足などの細部を描く。
持ち主テクスチャは1マス2バイト（約27MB）、地形テクスチャは1マス4バイト（約54MB）。
