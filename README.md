# 陣地取り大戦 ～1日1マスと核の時代～

1日に1マスだけ、となりのマスを**取る**か、自分のマスを**守る**陣地取りゲーム。
金を貯めて都市・ミサイル基地・迎撃基地を建て、核ミサイルで敵の陣地を吹き飛ばそう。

- **CPUと対戦**：ブラウザだけで遊べる（`public/index.html` を開くだけ）。オンライン版と同じ 440×560 のマップで、各国のCPU住民（合計1,000〜10,000人）も1人1日1マスずつ動く。100日のシーズンであなたの国の1位を目指す
- **AI会議（このブランチ）**：CPUの国のリーダーを本物のAI（Claude）が担当。「AI会議」で話し合い、同盟・裏切り・攻める国・核・新しいAIの国の呼び起こしを決める。claude.ai のアーティファクトで動かすと、遊ぶ人の Claude の利用枠を使って AI が考える（それ以外の場所では決まったルールで動く）
- **オンライン対戦**：みんなで国（チーム）に入り、1人1日1マスずつ広げる。1万人規模を想定（440×560＝約25万マス、陸地約14万マス）

## オンライン対戦のしくみ

- サーバーは Cloudflare Workers ＋ Durable Object（`server/worker.js`）。マップの正本はサーバーだけが持ち、行動の判定はすべてサーバーで行う
- 地図は最初に1回だけ圧縮して送り、あとは変わったマスだけを1秒ごとにまとめて配信（WebSocket）
- 日付は日本時間0時で切り替わる。100日でシーズン終了

### 不正対策（1日1マスを守る）

| 対策 | 内容 |
|---|---|
| アカウントごと | 「今日行動したか」はサーバーに記録。タブを何個開いても、別の端末からでも1日1回 |
| 回線（IP）ごとのアカウント作成 | 1回線から1日に作れるアカウント数に上限（初期値 2） |
| 回線ごとの行動回数 | 1回線から1日に行動できる回数に上限（初期値 2） |
| アクセス数 | 1回線から1分あたりのリクエスト数に上限（初期値 60） |
| 同時接続 | 1回線から同時に開けるタブ数に上限（初期値 6） |
| 監視・ブロック | `/admin.html` で回線ごとの記録（アカウント数・行動数・上限で止めた回数）を見て、回線をブロックできる |

- IP は生のまま保存せず、秘密の値（`IP_SALT`）と混ぜたハッシュで記録。管理画面には `203.0.113.xxx` のように一部を隠して表示
- 上限は `wrangler.toml` の `[vars]` で変えられる
- 注意：携帯回線・マンション・学校などでは別々の人が同じ IP になることがある。上限を厳しくしすぎると、正しく遊んでいる人まで止まるので、管理画面の記録を見ながら調整する

## 公開のしかた（オンライン対戦）

1. [Cloudflare](https://dash.cloudflare.com/sign-up) のアカウントを作る（無料プランで動く。人数が増えたら Workers Paid プランを検討）
2. このリポジトリで次を実行する

   ```sh
   npm install
   npx wrangler login
   npx wrangler secret put ADMIN_KEY   # 管理画面のキー（長いランダムな文字列）
   npx wrangler secret put IP_SALT     # IP をハッシュにするときに混ぜる値（長いランダムな文字列）
   npx wrangler deploy
   ```

3. 表示された `https://jintori.<アカウント名>.workers.dev` を開けば遊べる。管理画面は `/admin.html`
4. 新しいシーズンを始めるときは、管理画面の「シーズンをリセット」

### 手元で試す

```sh
printf 'DEV = "1"\nADMIN_KEY = "test"\nIP_SALT = "test"\n' > .dev.vars
npx wrangler dev
```

`DEV = "1"` のときだけ、`X-Test-IP` ヘッダーで IP を切り替えてテストできる（本番では無効）。

## ファイル構成

- `public/index.html` / `public/style.css` / `public/game.js` — 画面とゲーム（CPU対戦・オンライン対戦）
- `public/shared/map.js` — マップ生成（画面とサーバーで共通。同じ seed なら同じマップ）
- `public/admin.html` — 管理画面（回線の監視・ブロック・シーズンのリセット）
- `server/worker.js` — オンライン対戦サーバー
- `wrangler.toml` — Cloudflare の設定と、回線ごとの上限
